# EIA-861 2024 Master Dataset

Normalized extract of the U.S. Energy Information Administration **Form EIA-861
(2024)** electric utility survey, plus a joined utility-level master table.

Generated by `scripts/build_eia861_master.py` from the source workbooks shipped
in the repo root.

## Sources

| Workbook | Schedule | What it contains |
|---|---|---|
| `Frame_2024.xlsx` | Schedule 1 | Universe of 3,413 reporting utilities (id, name, ownership, which schedules they file) |
| `Utility_Data_2024.xlsx` | Schedule 2 | Ownership type, NERC region, operating regions |
| `Operational_Data_2024.xlsx` | Schedule 2 | Peak demand (S/W), net generation, energy purchases by source |
| `Short_Form_2024.xlsx` | 861-S | Small-utility short form: total revenue / sales / customers |
| `Balancing_Authority_2024.xlsx` | Reference | BA code lookup |
| `Service_Territory_2024.xlsx` | Schedule 8 | Counties served by each utility |
| `Delivery_Companies_2024.xlsx` | Schedule 8 | Delivery-only companies |
| `Distribution_Systems_2024.xlsx` | Schedule 3 | Number of distribution circuits / voltage-optimized circuits |
| `Reliability_2024.xlsx` | Schedule 3 | SAIDI / SAIFI / CAIDI by utility & state totals |
| `Sales_Ult_Cust_2024.xlsx` | Schedule 4 | Revenue / MWh / customers by sector (Res/Com/Ind/Trans) |
| `Sales_Ult_Cust_CS_2024.xlsx` | Schedule 4 | Customer-sited (behind-the-meter) sales detail |
| `Mergers_2024.xlsx` | Schedule 5 | 2024 utility mergers |
| `Energy_Efficiency_2024.xlsx` | Schedule 6A | Incremental & cumulative EE savings (MWh / MW) |
| `Demand_Response_2024.xlsx` | Schedule 6B | DR enrollments, peak savings, incentive payments |
| `Dynamic_Pricing_2024.xlsx` | Schedule 6C | Customers enrolled in TOU / RTP / CPP / CPR / VPP programs |
| `Advanced_Meters_2024.xlsx` | Schedule 6D | AMI / AMR / standard meter counts by sector |
| `Net_Metering_2024.xlsx` | Schedule 7A | Net-metered PV / wind / storage capacity & customer counts |
| `Non_Net_Metering_Distributed_2024.xlsx` | Schedule 7B | Non-net-metered distributed generation |

## Outputs

For each source sheet a cleaned CSV is written as
`<workbook_stem>__<sheet_slug>.csv` with:

- multi-row header blocks flattened into single column names (slugified),
- the EIA "." missing-data sentinel converted to empty,
- common identifier columns renamed to `data_year`, `utility_number`,
  `utility_name`, `state`, `ownership`, `ba_code`, etc.

`_source_summary.json` lists every output file with row/column counts and the
full column list — useful for downstream pipelines.

## `master_utility_2024.csv`

One row per Utility ID (3,413 utilities) joined onto the Frame spine. Columns:

| Group | Columns |
|---|---|
| Identity | `year`, `utility_id`, `utility_name`, `ownership_code`, `ownership`, `short_form`, `nerc_region` |
| Territory | `n_counties`, `states_served` |
| Sales (Schedule 4) | `sales_revenue_<sector>_k$`, `sales_sales_<sector>_mwh`, `sales_customers_<sector>` for sector ∈ {residential, commercial, industrial, transportation, total} |
| Metering (6D) | `ami_meters_total`, `amr_meters_total` |
| Demand Response (6B) | `dr_customers_total` |
| Dynamic Pricing (6C) | `dyn_pricing_customers_total` |
| Distributed PV (7A) | `net_metering_capacity_mw` |
| Reliability (3) | `saidi_minutes_per_year`, `saifi_per_year` (IEEE All-Events, mean across states) |
| Operations (2) | `summer_peak_mw`, `winter_peak_mw`, `net_generation_mwh`, `wholesale_purchases_mwh` |
| Efficiency (6A) | `ee_incremental_savings_mwh` |

Join key everywhere is **`utility_id`** (EIA Utility Number).

## Reproducing

```bash
source venv/bin/activate
pip install -r requirements.txt openpyxl pyarrow
python scripts/build_eia861_master.py
```

The script only depends on `pandas` and `openpyxl`. It is idempotent —
re-running overwrites the CSVs.
